# Sample Medical Documents

Place your medical documents here for testing. Supported formats:
- `.pdf` - Medical guidelines, research papers, drug references
- `.txt` - Clinical notes, plain text documentation
- `.csv` - Drug databases, patient records (anonymized)
- `.md` - Markdown formatted clinical guides

## Example Documents to Try

1. **WHO Clinical Guidelines** - Download from WHO website
2. **Drug Interaction Databases** - Available from FDA
3. **Clinical Practice Guidelines** - From medical associations
4. **Medical Textbook Excerpts** - Any medical reference text

> ⚠️ Never upload real patient data. Use anonymized or sample data only.
